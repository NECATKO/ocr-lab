# ocr-now + ocr-lab Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bugünkü `bench.py` karşılaştırma tezgâhını, ortak çekirdeği paylaşan iki komuta dönüştürmek: hocaya
kitap sayfası düzeninde `.docx` ve ham `.txt` üreten `ocr-now`, modelleri `gt/` ile ölçen `ocr-lab`.

**Architecture:** `src/ocrnow/` paketi. Bir sayfa şu adımlardan geçer:
1. Ana model sayfayı okur (varsayılan: dots.mocr düzen modu).
2. tesseract aynı sayfayı TSV olarak okur.
3. İkisinden modelden bağımsız bir `Page` yapısı kurulur: bloklar, satırlar ve işaretler. Bu yapı JSON olarak önbelleğe yazılır.
4. Dışa aktarıcılar (`.docx`, `.txt`) yalnızca `Page` okur.

`ocr-lab` aynı motor kaydını ve aynı hattı kullanıp ölçüm yapar. Model sunucuları bugünkü gibi ayrı ortamlarda
(`.venv-vllm`, `.venv-kraken`, llama.cpp) açılır. Ana program onlarla OpenAI uyumlu HTTP üzerinden konuşur.

**Tech Stack:** Python 3.12, uv, pypdfium2, pillow, python-docx, pytest. İsteğe bağlı `lab` eki: marimo.
Harici: tesseract (`tur`), vLLM 0.32.0, llama.cpp b11756, kraken 7.1.1.

**Spec:** `docs/superpowers/specs/2026-10-25-ocr-now-design.md`. Spike referansları:
`docs/superpowers/specs/2026-10-25-ocr-now-ekler/` (`spike_docx.py`, `cmp.py`, `layout_try.py`).
Spike verisi: `output/_spike/` (`dots_layout_syf1.json`, `tess_syf1.tsv`). Doğru metin: `gt/tarama5_syf1.txt`.

## Global Constraints

- Arayüz, mesajlar, komut satırı seçenek adları ve yorumlar **Türkçe**. Kod tanımlayıcıları İngilizce, mevcut `bench.py` gibi.
- Python 3.12. Ana ortam `.venv`, paket burada `uv pip install -e ".[dev]"` ile kurulur.
- Sabit sürümler: `VLLM=0.32.0`, `LLAMA=b11756`, `KRAKEN=7.1.1`, `KRAKEN_DOI=10.5281/zenodo.10592716`.
- VLM alt süreçlerinin ortamında `VLLM_USE_FLASHINFER_SAMPLER=0` olmalı ve `PATH` başında `.venv-vllm/bin:.venv-kraken/bin` bulunmalı.
- dots.mocr: `--quantization fp8 --enforce-eager --mm-processor-kwargs '{"max_pixels": 4000000}'`. deepseek-ocr2: fp8.
  Ortak vLLM bayrakları bugünkü `VLLM_FLAGS` ile aynı kalır.
- Aynı anda tek GPU işi. Sunucular sırayla açılıp kapatılır.
- Sayfalar hiçbir dış servise gönderilmez.
- **Bütün yollar yalnızca `src/ocrnow/paths.py`'den gelir.** Başka hiçbir modül `Path(__file__)` ya da sabit klasör adı kullanmaz.
- `input/`, `output/`, `gt/` ve kitap metni içeren hiçbir dosya git'e girmez. Testler ya kısa sentetik dizgiler kullanır
  ya da bu klasörlerdeki dosyaları okuyup yoksa `pytest.skip` ile atlanır.
- **Metne sadakat:** Hat, modelin harflerini değiştirmez. İzin verilen değişiklikler yalnızca şunlardır:
  kesme işaretinin türü (‘/’), satır sonuna tire eklenmesi, dipnot numarasının üst simge yapılması.
- Varsayılan motor ve mod tek bir yerde durur: `engines.DEFAULT_ENGINE = "dots.mocr"`, `engines.DEFAULT_MODE = "duzen"`.

### Görev 4: Sayfa veri modeli ve model çıktısını çözme

**Files:**
- Create: `src/ocrnow/layout.py`, `tests/test_layout.py`

**Interfaces:**
- Produces:
  ```python
  @dataclass
  class Mark:  start: int; end: int; kind: str          # "belirsiz" | "kesme"; Block.text içindeki karakter aralığı
  @dataclass
  class Line:  start: int; end: int; hyphen: bool       # hyphen: satır sonuna tire EKLENECEK (metinde yok)
  @dataclass
  class Block:
      category: str; bbox: tuple[int, int, int, int] | None; text: str
      lines: list[Line] = field(default_factory=list); indent: bool = False
      marks: list[Mark] = field(default_factory=list)
  @dataclass
  class Page:
      source: str; index: int; width: int; height: int; engine: str; mode: str
      blocks: list[Block]; tess_tsv: str = ""
      book_page: str | None = None; book_page_inferred: bool = False; book_page_side: str | None = None  # "sol" | "sag"
      warnings: list[str] = field(default_factory=list)
  def page_to_json(p: Page) -> str
  def page_from_json(s: str) -> Page
  def smart_resize(h: int, w: int, factor: int = 28, min_pixels: int = 3136, max_pixels: int = 4_000_000) -> tuple[int, int]
  def parse_output(raw: str, layout: bool, size: tuple[int, int]) -> tuple[list[Block], list[str]]   # size=(w,h)
  ```
- `Block.text` her zaman boşlukları sadeleştirilmiş tek satırdır (`" ".join(text.split())`).
- `parse_output` kuralları:
  - `layout=False`: tek bir `Block("Text", None, metin)` döner. Uyarı: `"düz metin modu: başlık, dipnot ve sayfa numarası ayrılamadı"`.
  - `layout=True`:
    - Baştaki/sondaki ` ```json ` çitleri soyulur.
    - Geçersiz ya da kesik JSON'da: tamamlanmış nesneler `json.JSONDecoder.raw_decode` ile tek tek kurtarılır, kalan
      metin tek Text bloğu olur. Uyarı: `"model çıktısı eksik/bozuk JSON: N blok kurtarıldı"`.
    - bbox'lar `smart_resize` boyutundan orijinal boyuta ölçeklenir.
    - `Picture` bloğunun metni `"[Görsel]"` olur.
- `smart_resize` (Qwen2-VL algoritması, imza tarafından belirlenmez):
  ```python
  h_bar, w_bar = round(h / factor) * factor, round(w / factor) * factor
  if h_bar * w_bar > max_pixels:
      beta = math.sqrt(h * w / max_pixels)
      h_bar, w_bar = math.floor(h / beta / factor) * factor, math.floor(w / beta / factor) * factor
  elif h_bar * w_bar < min_pixels:
      beta = math.sqrt(min_pixels / (h * w))
      h_bar, w_bar = math.ceil(h * beta / factor) * factor, math.ceil(w * beta / factor) * factor
  return h_bar, w_bar
  ```
